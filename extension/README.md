# Rewind for Chrome

1. Open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**.
2. Select the project's `extension` folder, which contains `manifest.json`.
3. Click **Rewind** in Chrome's Extensions menu to open a session. Its address field accepts addresses, domains, and search terms.

The BBC shortcut on the start page opens the March 1, 1995 capture. The early Google shortcut opens the November 11, 1998 capture. Click **Google Search Engine Prototype** on that capture to see the separately archived Stanford Google site.

Rewind checks the Wayback index for 1995 first, then checks the earliest captures from other years. It verifies the replay timestamp, skips failed replays, and uses retro styling on the live page when the archive lookup fails. Pages load as regular Chrome tabs and can keep their existing framing protections.

Keyword searches show inline results from [Wiby’s public JSON API](https://wiby.me/json/), which indexes the classic web and requires no API key or server setup. Matching Rewind history appears below the web results. Page and search history persist in the Chrome profile until you click **Clear history**. New Rewind sessions start from the extension icon.
